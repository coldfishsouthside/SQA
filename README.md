# SQA Quick Fill

Phone form that fills in the original Southside SQA PDF (TAB 9-05).
Pick a role, answer only the questions for that role, then save the filled PDF.
Everything runs in the browser. No data is sent to any server.

Draft: wording and a few boxes are still waiting for confirmation from Southside QA.

## Publish with GitHub Pages
1. Upload `index.html` (and `.nojekyll`) to the repository root.
2. Settings > Pages > Build and deployment > Source: Deploy from a branch.
3. Branch: main, folder: / (root). Save.
4. The link appears after a few minutes: `https://<username>.github.io/<repository>/`

## Update
Replace `index.html` with the new file and commit. The link stays the same.
